## How to start
### run the following command

Indoor dataset：

```shell
blender -b ./indoor.blend -P ./indoor.py
```

Ourdoor dataset：

```shell
blender -b ./outdoor.blend -P ./outdoor.py
```

You can download our dataset sence at [https://drive.google.com/drive/folders/1TjVv01WxVHClVdCdnm6T4eguckKv27-Z?usp=sharing](https://drive.google.com/drive/folders/1TjVv01WxVHClVdCdnm6T4eguckKv27-Z?usp=sharing)

### requirement

- blender=3.3

The following packages need to be installed in Blender's built-in Python environment.

- Python=3.10.13
- Pillow=10.2.0
- pycocotools=2.0.7
- numpy=1.22.0
- opencv-python=4.5.4.60
